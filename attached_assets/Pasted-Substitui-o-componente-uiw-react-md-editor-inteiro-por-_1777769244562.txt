nativa em artifacts/decksensei/app/admin/prompts/_components/PromptEditor.tsx.
A biblioteca está com bug interno na captura de seleção do cursor (a v4.1.0
mudou estrutura de DOM e o fix anterior com selectionchange listener não
funciona). Em vez de tentar mais workarounds, troca pela primitive nativa.

4. Simplifica drasticamente o useEffect que captura posição do cursor — agora

   no document. APAGA o useEffect inteiro que existe hoje.

5. Reescreve insertVariable pra ser trivial (textarea nativa expõe
   selectionStart/selectionEnd diretamente):

   const insertVariable = useCallback((varKey: string) => {
     const tag = `{{${varKey}}}`;
     const ta = textareaRef.current;
     if (!ta) return;
     const start = ta.selectionStart;
     const end = ta.selectionEnd;
     const newContent = content.slice(0, start) + tag + content.slice(end);
     setContent(newContent);
     // Reposiciona cursor após o tag inserido
     requestAnimationFrame(() => {
       ta.focus();
       const newPos = start + tag.length;
       ta.setSelectionRange(newPos, newPos);
     });
   }, [content]);

   Note: deps tem [content] agora porque a função usa o content atual via
   ta.selectionStart, mas o setContent precisa do content sincronizado.
