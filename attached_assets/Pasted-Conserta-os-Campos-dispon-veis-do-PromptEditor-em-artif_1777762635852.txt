Conserta os "Campos disponíveis" do PromptEditor em
artifacts/decksensei/app/admin/prompts/_components/PromptEditor.tsx — eles não
funcionam: clicar em "inserir" sempre joga a variável no início do prompt,
nunca na posição do cursor.

Diagnóstico:
1. O fallback `ta.selectionStart ?? content.length` não dispara porque quando
   o foco sai da textarea (ao clicar no botão), selectionStart vira 0 — não
   null/undefined.
2. O botão <button> rouba foco da textarea ao ser clicado, perdendo a posição
   do cursor.
3. document.querySelector é frágil e usa estado da closure (`content`) que
   pode estar stale entre cliques rápidos.

Solução completa:

(a) Adiciona uma ref que rastreia a última posição conhecida do cursor enquanto
    a textarea está focada:

    const lastCursorRef = useRef<{ start: number; end: number } | null>(null);

    useEffect(() => {
      const ta = document.querySelector<HTMLTextAreaElement>(
        ".w-md-editor-text-input"
      );
      if (!ta) return;
      const handler = () => {
        if (document.activeElement === ta) {
          lastCursorRef.current = {
            start: ta.selectionStart ?? 0,
            end: ta.selectionEnd ?? 0,
          };
        }
      };
      document.addEventListener("selectionchange", handler);
      return () => document.removeEventListener("selectionchange", handler);
    }, []);

(b) Reescreve insertVariable usando o functional updater de setState (evita
    stale closure) e a posição salva na ref:

    const insertVariable = useCallback((varKey: string) => {
      const tag = `{{${varKey}}}`;
      const pos = lastCursorRef.current;
      setContent((prev) => {
        if (!pos) return prev + tag;          // nunca focou — vai pro fim
        return prev.slice(0, pos.start) + tag + prev.slice(pos.end);
      });
      requestAnimationFrame(() => {
        const ta = document.querySelector<HTMLTextAreaElement>(
          ".w-md-editor-text-input"
        );
        if (ta && pos) {
          const newPos = pos.start + tag.length;
          ta.focus();
          ta.setSelectionRange(newPos, newPos);
          lastCursorRef.current = { start: newPos, end: newPos };
        }
      });
    }, []);

    Note: o array de deps fica vazio agora (não depende de `content`).

(c) No botão "inserir" dentro do .map de VARIABLES, adiciona onMouseDown que
    previne o roubo de foco:

    <button
      type="button"
      onMouseDown={(e) => e.preventDefault()}   // ← linha nova
      onClick={() => insertVariable(v.key)}
      className="..."
    >
      inserir
    </button>

    array VARIABLES, assim o filho vê uma aproximação do resultado real em vez
    de {{game_name}} literal:

    Antes do return, calcula:
    const previewContent = VARIABLES.reduce((acc, v) => {
      return acc.replaceAll(`{{${v.key}}}`, v.example);
    }, content);

    E no <ReactMarkdown> troca {content} por {previewContent}.
