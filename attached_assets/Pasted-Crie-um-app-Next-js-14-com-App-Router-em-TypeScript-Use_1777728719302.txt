Crie um app Next.js 14 com App Router em TypeScript. Use Tailwind CSS e instale shadcn/ui com tema neutro. Configure Postgres do Replit usando Drizzle ORM.

Schema TCG-agnóstico desde o início — TODAS as tabelas que armazenam conteúdo de jogo precisam de coluna game_id varchar (indexed):

- games (id varchar PK, name varchar, config jsonb, created_at) — popular com row { id: 'digimon', name: 'Digimon Card Game', config: {...} } no seed
- users (id serial PK, email varchar unique, city varchar nullable, state varchar nullable, created_at, last_seen_at)
- magic_tokens (token_hash varchar unique, user_id FK, expires_at, used_at)
- meta_snapshots (id serial, game_id varchar FK, version varchar, json_content jsonb, notes text nullable, scope varchar default 'global', active boolean default false, created_at) + índice único parcial garantindo só uma ativa por (game_id, scope)
- prompts (id serial, game_id varchar FK, version varchar, system_content text, notes text nullable, active boolean default false, created_at) + índice único parcial garantindo só uma ativa por game_id
- analyses (id varchar PK nanoid, game_id varchar FK, user_id FK nullable, deck_text text, deck_parsed jsonb, analysis_text text, prompt_version_id FK, meta_snapshot_id FK, similar_archetype_id varchar nullable, response_time_ms int, is_featured boolean default false, deleted_at timestamp nullable, admin_note text nullable, created_at)
- analysis_feedback (id serial, analysis_id FK, rating varchar check(rating in('up','down')), comment text nullable, ip varchar, created_at)
- api_costs (id serial, analysis_id FK nullable, input_tokens int, output_tokens int, cost_usd numeric(10,6), is_test boolean default false, created_at)
- rate_limits (id serial, key varchar indexed, count int, window_start timestamp)
- sessions (id varchar PK, user_id FK, expires_at, created_at)

Crie estrutura de pastas:
- /app
- /components
- /lib
- /lib/games/types.ts (interfaces CardAPI, DeckParser, DeckValidator)
- /lib/games/digimon/ (vai conter card-api.ts, deck-parser.ts, deck-validator.ts no Épico 2)

Adicione .env.example listando: ANTHROPIC_API_KEY, DATABASE_URL, RESEND_API_KEY, ADMIN_TOKEN (string aleatória 32+ chars), DAILY_COST_CAP_USD (default "10"), APP_URL (URL pública da app).

App deve subir limpo em modo dev e mostrar página em branco em /digimon (raiz / redireciona pra /digimon).
